# Examples

Sample records showing the maestro record formats — **demo content, not real decisions or results**.
The projects, metrics, and decisions in here are invented for illustration (a fictional fleet/ML project).

- `docs/adrs/` — four sample ADRs + the generated `INDEX.md` (note the `superseded → adr_4` chain in adr_03)
- `docs/experiments/` — four sample experiment records + generated `INDEX.md` (covers `outcome: infra`, `improved`, and `refuted`)

These files are static snapshots: their `INDEX.md` files were generated by `maestro index render`
when they lived under `docs/`, and are kept as examples of the generated output. Real records live
in each project's (untracked) `docs/` tree and are always created via the `maestro` CLI — never by hand.
